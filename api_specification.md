# PIH Evaluation API Specification

This document defines the exact **inputs (request payloads)** and **outputs (response schemas)** for the four evaluation API endpoints. Users must implement these endpoints on their prototype servers for the AI Evaluation Framework to programmatically grade their systems.

All endpoints must return JSON and use standard HTTP status codes (e.g. `200 OK`, `400 Bad Request`, `500 Internal Server Error`).

---

## 🔑 Shared Objects

### Performance Metadata Schema (`PerformanceMetadata`)
Every endpoint response must include this object in the `performance_metadata` field to allow the framework to calculate **Latency (5%)** and **Cost Efficiency (5%)** scores.

```json
{
  "type": "object",
  "properties": {
    "latency_ms": {
      "type": "number",
      "description": "Total backend processing latency for this request in milliseconds."
    },
    "prompt_tokens": {
      "type": "integer",
      "description": "Number of prompt tokens sent to the LLM (0 if no LLM was used)."
    },
    "completion_tokens": {
      "type": "integer",
      "description": "Number of completion tokens generated by the LLM (0 if no LLM was used)."
    },
    "total_tokens": {
      "type": "integer",
      "description": "Total prompt + completion tokens used."
    },
    "model_used": {
      "type": "string",
      "description": "Full model identifier used (e.g., 'gpt-4o-mini', 'claude-3-5-sonnet-20240620')."
    }
  },
  "required": ["latency_ms", "prompt_tokens", "completion_tokens", "total_tokens", "model_used"]
}
```
